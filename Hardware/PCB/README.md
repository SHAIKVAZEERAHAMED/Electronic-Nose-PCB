# Printed Circuit Board (PCB)

This directory contains the PCB layout, fabrication outputs, and mechanical design of the Electronic Nose system.

## Overview

The Electronic Nose hardware was implemented as a compact printed circuit board (PCB) designed using KiCad 9.0.7. The layout integrates the MEMS gas sensor array, analog front-end circuits, processing units, heater control circuitry, and power management subsystem into a single modular platform.

## PCB Features

- Compact PCB layout
- Fourteen-channel MEMS gas sensor array
- Modular subsystem placement
- Battery-powered operation
- Dedicated analog and digital sections
- Detachable sensor board
- Design optimized for future expansion

## PCB Design Considerations

The PCB layout was designed with emphasis on:

- Functional component grouping
- Short analog signal paths
- Efficient power distribution
- Stable ground connections
- Heater and signal isolation
- Manufacturability

## Board Contents

The PCB includes the following functional blocks:

- MEMS Gas Sensor Array
- Analog Front End
- ESP32-S3 Controller
- RP2040 PWM Controller
- Heater Driver
- Power Management
- Environmental Sensor
