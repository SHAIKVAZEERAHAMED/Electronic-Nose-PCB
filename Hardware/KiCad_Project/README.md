# KiCad Project

This directory contains the complete KiCad project files for the Electronic Nose hardware.

## Overview

The Electronic Nose PCB was designed using **KiCad 9.0.7**. This folder includes all project files required to open, edit, verify, and manufacture the PCB.

## Software Version

- KiCad 9.0.7

## Project Files

| File | Description |
|------|-------------|
| *.kicad_pro | KiCad project file |
| *.kicad_sch | Complete schematic |
| *.kicad_pcb | PCB layout |

## Design Features

- Multi-sheet schematic
- Fourteen-channel MEMS gas sensor array
- Dual microcontroller architecture
- Analog front-end circuitry
- Power management subsystem
- Two-layer PCB layout
- Design Rule Check (DRC) verified
- Electrical Rule Check (ERC) verified

## How to Open

1. Install **KiCad 9.0.7** or later.
2. Open the `.kicad_pro` file.
3. Use the Schematic Editor to view the circuit design.
4. Use the PCB Editor to inspect or modify the layout.

## Folder Contents

This folder will contain:

- KiCad project
- Schematics
- PCB layout
- Custom symbols
- Custom footprints
- Manufacturing outputs
